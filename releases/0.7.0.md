# Sapid 0.7.0

Sapid 0.7.0 targets Glory 0.7.0, requires Rust 1.95 and uses Cargo resolver 3.

- Typed Rust builders and Glory's optional XML syntax use one Widget contract,
  including shared mixed-tree SSR, hydration and native entry points.
- Controlled inputs propose changes through typed callbacks; local defaults,
  reconciliation, editor revisions and teardown follow Glory's Owner model.
- The catalog records finite implementations across 268 upstream entries and
  149 work items, with per-widget API comparisons and host capability evidence.
  Catalog completion does not imply complete Mantine/shadcn feature parity.
- Specialized JSON, code, dates, charts, files, editor and chat families remain
  opt-in. The default normal dependency graph keeps application host selection
  outside widget state.
- The showcase version label reads the linked Sapid package version.
- Routine CI retains widget behavior and representative showcase acceptance,
  runs isolated suites in parallel and reuses dependency/tool caches. Scheduled
  and release acceptance retain the complete page and palette matrix.
- Blue/Green light and dark presets, explicit custom palettes and Theme Studio
  support application-owned theme configuration.
- The project README now provides concise setup, Rust/XML examples, feature
  tables and links to the detailed widget and theme guide.

The release workflow freezes product, Glory and browser-harness revisions,
requires complete acceptance reports with source/fixture hashes, and reuses the
exact validated library lockfile for publication. The release includes browser
provenance and an independently verified registry-only consumer.

Native support remains specific to each widget and operation. Unsupported
facets return typed errors. Native rich-document editing, OS IME, physical-device
and screen-reader speech acceptance are not inferred from browser/model tests.
See the capability ledger and verification record for the current boundaries.

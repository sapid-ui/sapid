# Sapid 0.7.1

Sapid 0.7.1 continues to use Glory 0.7.0 and requires Rust 1.95.

- Fix continuous ColorInput hue and opacity dragging: preserve accepted picker
  precision across formatted color round trips so dragging continues through
  later pointer moves. Controlled refusal and external updates remain authoritative.
- Keep Rating's focus outline visible for keyboard navigation in the public
  showcase while hiding the half-star box after pointer selection.
- Select CI checks by the complete change scope. Markdown-only changes avoid
  Rust/native builds; showcase styles keep website builds and browser behavior
  acceptance while skipping the full widget/native, MSRV and audit suites.
- Include changes since the last successful ancestor CI run, so a later CSS or
  documentation push cannot hide an unvalidated library change. Release checks
  retain full Rust/native/widget and page/palette acceptance.
- The showcase version label follows the linked Sapid package version.

Glory and engine dependency versions are unchanged. The release workflow checks
the frozen product source, publishes the Sapid crate, and verifies an independent
crates.io-only DSL/SSR/native consumer before completing the GitHub release.
